MongoDB Aggregation Analytics

Real-time business and clinical intelligence powered by multi-stage aggregation pipelines: $match, $group, $unwind, $lookup, $facet

PIPELINE 1

Department Patient Volumes & Financial Revenue

Stages: $match → $group → $project → $sort

db.patients.aggregate([
  { $match: { status: { $ne: "Archived" } } },
  {
    $group: {
      _id: "$department",
      total_patients: { $sum: 1 },
      average_age: { $avg: "$age" },
      total_revenue: { $sum: "$billing.total_amount" },
      avg_bill: { $avg: "$billing.total_amount" }
    }
  },
  { $sort: { total_revenue: -1 } }
]);

PIPELINE 2

Doctor Workload & Revenue Allocation ($lookup Join)

Stages: $lookup (cross collection with patients) → $project → $sort

db.doctors.aggregate([
  {
    $lookup: {
      from: "patients",
      localField: "doctor_id",
      foreignField: "assigned_doctor_id",
      as: "patient_records"
    }
  },
  {
    $project: {
      doctor_id: 1,
      name: 1,
      department: 1,
      patient_count: { $size: "$patient_records" },
      total_revenue: { $sum: "$patient_records.billing.total_amount" }
    }
  },
  { $sort: { patient_count: -1 } }
]);

PIPELINE 5

Multi-Faceted Executive KPI Breakdown ($facet)

Executes multiple parallel aggregation pipelines in a single database round-trip!

db.patients.aggregate([
  {
    $facet: {
      status_summary: [
        { $group: { _id: "$status", count: { $sum: 1 } } }
      ],
      billing_summary: [
        {
          $group: {
            _id: "$billing.payment_status",
            total_billed: { $sum: "$billing.total_amount" },
            patient_count: { $sum: 1 }
          }
        }
      ]
    }
  }
]);
