Why Use MongoDB as a Vector Database? (Viva Defense)

Single Data Store (No Sync Drift) Traditional setups require syncing MongoDB with an external vector store (Pinecone/Weaviate). With MongoDB Vector Search, transactional data, vitals, billing, and vector embeddings reside in the exact same document.
Pre-Filtering with Metadata MongoDB allows combining traditional metadata filters (e.g. department: "Cardiology") with vector similarity searches in a single aggregation pipeline without performance loss.
Standard BSON Compatibility Embeddings are stored natively as standard arrays of IEEE 754 floating-point numbers (bsonType: "double"), queryable via standard PyMongo drivers.
